# Deploying

The package is published to npm as `@tallio/contentful-mock`. Only the `dist/` folder is included (see `files` in `package.json`).

## Release checklist

1. Make sure you are on `main` with a clean working tree.
2. Verify everything passes:

   ```bash
   npm ci
   npm run lint
   npm test
   npm run build
   ```

3. Bump the version, update `CHANGELOG.md` from the Conventional Commit history, commit and tag. The bump is inferred from commits (`fix:` → patch, `feat:` → minor, `!`/`BREAKING CHANGE` → major):

   ```bash
   npm run release:dry                 # preview the version and changelog entry
   npm run release                     # apply it
   npm run release -- --release-as minor   # or force patch / minor / major
   ```

   To only regenerate the changelog without bumping or tagging, run `npm run changelog`.

4. Inspect what will be published:

   ```bash
   npm pack --dry-run
   ```

5. Publish (scoped packages are private by default, so pass `--access public`):

   ```bash
   npm login
   npm publish --access public
   ```

6. Push the commit and tag:

   ```bash
   git push --follow-tags
   ```

## Notes

- `dist/` is generated by `npm run build` and must be built before publishing.
- `contentful` and `contentful-management` are optional peer dependencies; they are not bundled.
- The `examples/` directory is not published.
